# JFTSE Item Finder

## Development

Install dependencies:

```sh
bun install
```

Build the browser bundle and start the local server:

```sh
bun run build
bun run start
```

Open <http://127.0.0.1:4173>. The server proxies the live shop API while
serving the precomputed catalog and artwork from `assets/`.

## Validation

```sh
bun run typecheck
bun test
bun run clean
bun run build
```

`script.js` is generated by Bun and intentionally ignored. GitHub Pages builds
the bundle in CI before assembling the static site.

## Catalog generation

Regenerate `assets/catalog.json` from the configured JFTSE source data:

```sh
bun run generate:catalog
```
